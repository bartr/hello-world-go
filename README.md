# hello-world-go

A tiny free-standing Go command-line app that prints a greeting. It is the
upstream repository for the `hello-world-go` task in the DeepSWE / Harbor
benchmark: the task pins a base commit of this repo and asks an agent to make
one small, well-specified change.

## Run

```sh
go run ./cmd/hello
```

## Test

```sh
go test ./...
```
